Agilent 1200 RRLC Operating Guide

Rapid Resolution Liquid Chromatography HP 1200 (Agilent ChemStation)

Detailed procedural manual for high-pressure binary gradient screening: module startup, manual purge valve deaeration, ChemStation method configuration, DAD spectral acquisition (190–400 nm), sequence table automation, offline peak integration, and spectral overlay analysis.

Document PKKK/300/UP/003 (10 April 2026)
Instrument Agilent 1200 Series RRLC / UHPLC
Software Agilent ChemStation (RRLC Online & Offline)
Detector Diode Array Detector (DAD SL)
Passcode Windows / ChemStation: 3000hanover
FASA 1: STARTUP & PURGING

1.0 Tatacara Memulakan RRLC & Nyahgas Saluran (Purging)

Ref: PKKK/300/UP/003 Para 6.1.1 – 6.1.9
  1. Suis Kuasa: Buka semua suis utama bekalan elektrik, suis modul-modul 1200 Series UHPLC, PC ChemStation, dan mesin pencetak.
  2. Kata Laluan Log Masuk: Masukkan kata laluan: 3000hanover dan tekan OK.
  3. Fasa Bergerak: Masukkan botol pelarut yang telah ditapis 2 kali menggunakan membran 0.45 µm. Pastikan batu penuras (solvent inlet filter) terendam di dalam pelarut tanpa menyentuh dinding botol.
  4. Buka Perisian: Klik dua kali ikon RRLC Online pada desktop.
  5. Pengaktifan Modul: Pilih tab Method & Run Control $\rightarrow$ Klik butang ON. Tunggu sehingga semua ikon modul bertukar kepada warna hijau (keadaan sedia / ready).
  6. Muat Turun Kaedah: Pilih menu Method $\rightarrow$ Load Method (pilih kaedah analisis yang dikehendaki).
  7. Nyahgas Injap Purge Manual (Purging):
    • Buka kepala injap purge pada pam (pusing lawan arah jam sebanyak 1/2 hingga 1 pusingan).
    • Klik kanan pada ikon Binary Pump $\rightarrow$ Method.
    • Tetapkan kadar alir (flow rate): 5.00 mL/min.
    • Tetapkan Pelarut A: 100% (saluran lain 0%). Alirkan selama 3 minit.
    • Ulangi langkah di atas secara bergilir-gilir untuk Pelarut B (100%), C, dan D selama 3 minit setiap satu.
    • Pastikan tiada gelembung udara dalam tiub dan bacaan tekanan adalah stabil.
  8. Tutup Injap Purge & Naikkan Aliran:
    • Klik kanan Binary Pump $\rightarrow$ Method $\rightarrow$ Pilih saluran pelarut kaedah $\rightarrow$ Set kadar alir kepada 0.1 mL/min $\rightarrow$ Klik OK.
    • Tutup kepala injap purge (pusing mengikut arah jam sehingga ketat dengan jari).
    • Naikkan kadar alir sedikit demi sedikit (ramping) sehingga mencapai kadar alir analisis yang ditetapkan (contoh: 1.0 mL/min).
FASA 2: IMBANGAN & DETECTOR

2.0 Penstabilan Garisan Dasar, Thermostat & Pengesan DAD

Ref: PKKK/300/UP/003 Para 6.1.10 – 6.1.13
  1. Penstabilan Baseline (Zero / Balance): Alirkan fasa bergerak selama 15–30 minit. Klik butang Adjust dan seterusnya Balance untuk menetapkan garisan dasar kepada sifar.
  2. Tetapan Suhu Ketuhar Kolum (Thermostat):
    Klik kanan ikon Thermostat $\rightarrow$ Method $\rightarrow$ Masukkan suhu sasaran analisis (contoh: 30 °C atau 40 °C) $\rightarrow$ Klik OK.
  3. Tetapan Pengesan DAD (Diode Array Detector):
    Klik kanan ikon DAD $\rightarrow$ Method:
    • Signal: Masukkan panjang gelombang analit (contoh: 240 nm, 280 nm, atau 284 nm) dengan lebar jalur (Bandwidth: 4 nm).
    • Spectrum Storage: Pilih Store: All
    • Spectrum Range: 190 to 400 nm
    • Step: 2.0 nm $\rightarrow$ Klik OK.
  4. Jadual Waktu Gradien (Timetable):
    Jika menggunakan gradien: Klik kanan Binary Pump $\rightarrow$ Method $\rightarrow$ Pada bahagian Timetable, klik Add untuk memasukkan masa, % Pelarut B, dan kadar alir mengikut arahan kerja.
  5. Simpan Kaedah: Klik menu Method $\rightarrow$ Save Method As... $\rightarrow$ Masukkan nama fail kaedah dan catatan ringkas.
FASA 3: SEQUENCE OTOMASI

3.0 Penyediaan & Pelaksanaan Sequence Injection

Ref: PKKK/300/UP/003 Para 6.1.14 – 6.1.16
  1. Parameter Sequence:
    Klik Sequence [Toolbar] $\rightarrow$ Sequence Parameters:
    • Operator Name: Masukkan nama/jawatan penganalisis.
    • Data File / Subdirectory: Masukkan nama folder unik penyimpanan data batch.
    • Klik OK.
  2. Jadual Suntikan (Sequence Table):
    Klik Sequence $\rightarrow$ Sequence Table $\rightarrow$ Masukkan butiran berikut:
    Medan ParameterKeterangan & Nilai Input
    Sample LocationPilih lokasi kedudukan vial dari menu lungsur (dropdown: cth Vial 1, Vial 2).
    Sample NameNama unik sampel / standard / blank mengikut lembaran kerja.
    Method NamePilih fail kaedah yang berkaitan (.M).
    Inj / LocBilangan suntikan untuk satu vial (contoh: 1 untuk blank, 6 untuk SST, 2 untuk sampel).
    Sample TypePilih: Sample / Calibration / Blank.
    Update RF / RTPilih: Average.

    Klik butang Append Line untuk menambah baris suntikan seterusnya $\rightarrow$ Klik OK.

  3. Simpan & Jalankan Sequence:
    Klik Sequence $\rightarrow$ Save Sequence Template As... $\rightarrow$ Masukkan nama fail.
    Klik Run Control $\rightarrow$ Run Sequence untuk memulakan analisis automatik.
FASA 4: ANALISIS DATA & SPEKTRA

4.0 Pemprosesan Kromatogram, Integrasi & Spektrum Pertindihan (Overlay)

Ref: PKKK/300/UP/003 Para 6.2 & 6.3
  1. Buka Mod Offline: Klik dua kali ikon RRLC Offline pada desktop.
  2. Muat Data: Klik File $\rightarrow$ Load Signal... $\rightarrow$ Pilih fail kromatogram sampel $\rightarrow$ Klik OK.
  3. Tetapan Parameter Integrasi:
    Klik Integration $\rightarrow$ Integration Events $\rightarrow$ Masukkan nilai Slope Sensitivity, Height Reject, dan Area Reject $\rightarrow$ Klik Exit dan simpan perubahaan (Yes).
  4. Pemerhatian Spektrum UV Analit:
    Klik Spectra [Toolbar] $\rightarrow$ Select Peak Spectra $\rightarrow$ Klik pada puncak analit dalam kromatogram. Imej spektrum UV (190–400 nm) bagi puncak tersebut akan dipaparkan.
  5. Pertindihan Spektrum (Spectra Overlay) Sampel vs Standard:
    • Klik File $\rightarrow$ Overlay Signal... $\rightarrow$ Pilih fail kromatogram Piawai Rujukan.
    • Klik pada imej puncak sampel.
    • Tekan serentak butang: Ctrl + Alt + Klik pada puncak Standard.
    • Imej spektrum standard akan bertindih (overlay) tepat di atas spektrum sampel bagi verifikasi identiti analit.
  6. Cetak Laporan: Klik Report [Toolbar] $\rightarrow$ Print.
FASA 5: PENCUCIAN & SHUTDOWN

5.0 Tatacara Pencucian Turus & Penutupan Lengkap Sistem

Ref: PKKK/300/UP/003 Para 6.4 & 6.5
🧼 PROTOKOL PENCUCIAN SISTEM (SYSTEM WASHING):
1. Alirkan pelarut 5% Methanol dalam Air (ditapis 0.45 µm) selama 1 jam pada kadar alir 1.0 mL/min untuk menyingkirkan garam penimbal.
2. Alirkan 100% Acetonitrile atau Methanol selama 30 minit pada kadar 1.0 mL/min sebagai pelarut penyimpanan kolum.

Tatacara Shutdown Harian:

  1. Klik ikon DAD $\rightarrow$ Control $\rightarrow$ UV Lamp $\rightarrow$ Off $\rightarrow$ OK.
  2. Klik ikon Thermostat $\rightarrow$ Control $\rightarrow$ Off $\rightarrow$ OK.
  3. Klik ikon Pump $\rightarrow$ Set up pump $\rightarrow$ Turunkan kadar alir sedikit demi sedikit sehingga 0.00 mL/min $\rightarrow$ OK.
  4. Klik File $\rightarrow$ Exit $\rightarrow$ Close RRLC Online?: Yes.
  5. Switch off LC pump, thermostat and lamp?: Yes.
  6. Tutup suis komputer (Shut down PC) dan padamkan suis utama modul Agilent 1200.
  7. Isi dan tandatangan buku log: Rekod Penyelenggaraan Alat Rapid Resolution Liquid Chromatography HP1200.
