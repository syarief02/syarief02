1.0 TUJUAN

Untuk memastikan langkah-langkah yang terlibat dalam proses pengendalian alat Rapid Resolution Liquid Chromatography HP1200 semasa pengujian sampel dijalankan dengan cekap dan selamat.

2.0 SKOP

Prosedur ini hendaklah digunakapakai semasa mengendalikan alat RRLC HP1200 bagi pengujian produk tradisional, suplemen kesihatan dan kosmetik.

3.0 DEFINISI

RRLC: Rapid Resolution Liquid Chromatography (Kromatografi Cecair Resolusi Pantas).

4.0 CARTA ALIRAN

Tiada carta aliran untuk prosedur ini.

5.0 TANGGUNGJAWAB

5.1 Ketua Unit / Pegawai Farmasi Bertanggungjawab:

Memastikan prosedur ini diikuti semasa pengendalian alat ini.

5.2 Pegawai Farmasi:

a) Menyelia proses pengendalian alat ini oleh Penolong Pegawai Farmasi.
b) Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

5.3 Penolong Pegawai Farmasi U7 / U6:

Memastikan penyelenggaraan alat ini dijalankan pada waktu yang ditetapkan dan menyimpan rekod penyelenggaraan alat.

5.4 Penolong Pegawai Farmasi:

Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

6.0 PROSEDUR
6.1 Tatacara Penggunaan
  1. Buka semua suis utama.
  2. Buka semua suis 1200 series UHPLC modules, Agilent Chemstation PC dan mesin pencetak.
  3. Masukkan password: 3000hanover – Tekan OK.
  4. Klik pada RRLC Online 2x. (Letakkan botol pelarut yang diisi penuh dengan pelarut/fasa gerak yang dikehendaki mengikut analisis. Pastikan solvent inlet filter mencecah fasa gerak dan tidak terkena dinding botol. Semua pelarut MESTI ditapis menggunakan penapis membran 0.45 µm sebanyak 2 kali).
  5. Pilih tab Method & Run Control.
  6. Klik butang ON (Tunggu sehingga semua gambarajah pada ikon ini menjadi hijau $\rightarrow$ keadaan bersedia).
  7. Pilih ikon METHOD – load method (berdasarkan ujian yang hendak dijalankan).
  8. Purging:
    • Buka kepala injap purge (pusing lawan arah jam).
    • Klik kanan pada bahagian Binary pump $\rightarrow$ “Method”.
    • Tetapkan kadar aliran: 5.00 mL/min, pelarut A: 100% (pelarut lain 0%).
    • Pastikan kesemua pam melalui proses purging secara bergilir-gilir (100%) dalam selang masa 3 minit setiap satu. Pastikan tiada gelembung udara pada pam dan kadar tekanan pada pump status adalah stabil.
  9. Klik kanan pada bahagian Binpump $\rightarrow$ “Method” $\rightarrow$ Klik bahagian Solvent dan pilih pam yang ingin digunakan $\rightarrow$ Tetapkan kadar aliran: 0.1 mL/min $\rightarrow$ Klik OK dan tutup kepala injap (pusing arah jam).
  10. Naikkan kadar aliran sedikit demi sedikit sehingga perkadaran yang diinginkan.
  11. Tunggu sehingga garisan dasar stabil. Klik butang Adjust dan Balance (Tunggu sehingga 30 minit).
  12. Klik kanan ikon thermostat $\rightarrow$ Method (masukkan suhu yang dikehendaki) $\rightarrow$ Klik OK.
  13. Klik kanan ikon DAD $\rightarrow$ Method:
    • Signal: masukkan nilai detector (nm) yang dikehendaki.
    • Spectrum: Store: All, Range: 190 to 400 nm, Step: 2.0 nm $\rightarrow$ Klik OK.
  14. Jika ingin menggunakan gradient: Klik kanan ikon binary pump $\rightarrow$ Method, pada ruangan timetable klik Add dan masukkan data yang dikehendaki $\rightarrow$ Klik OK.
  15. Klik Method [Toolbar] $\rightarrow$ Save Method As (masukkan sebarang komen mengenai analisis secara ringkas pada Method Information) $\rightarrow$ Klik OK.
  16. Untuk jalankan analisis secara SEQUENCE:
    • Klik Sequence [Toolbar] $\rightarrow$ Sequence Parameter (Operator name, Data file subdirectory) $\rightarrow$ Klik OK.
    • Klik Sequence [Toolbar] $\rightarrow$ Sequence Table $\rightarrow$ Insert table:
      • Sample location: lokasi vial (dropdown menu)
      • Sample name: nama sampel
      • Method name: fail kaedah
      • Inj/Loc: bilangan injeksi
      • Sample type: dropdown menu
      • Update RF: Average · Update RT: Average
      • Klik “Append Line” untuk menambah baris $\rightarrow$ Klik OK.
    • Klik Sequence [Toolbar] $\rightarrow$ Save Sequence Template As $\rightarrow$ Masukkan nama fail $\rightarrow$ Klik OK.
    • Klik Run Control $\rightarrow$ Run Sequence (*Pastikan anda tidak menindih / replace master method yang sedia ada).
6.2 Sebelum Memulakan Analisis (Integrasi & Laporan)
  1. Untuk mengubah data / peak yang diperolehi dalam laporan: Klik View $\rightarrow$ pilih Data Analysis $\rightarrow$ Report $\rightarrow$ Specify Report $\rightarrow$ Signal Option (Tetapkan Min Value dan Max Value untuk Time Range dan Response Range).
  2. Untuk menetapkan minimum area, height dan slope sensitivity:
    Klik Integration $\rightarrow$ Integration Events:
    • Slope sensitivity: set value
    • Height reject: set value
    • Area reject: set value
    Klik Exit $\rightarrow$ Save changed events tables? $\rightarrow$ Yes.
  3. Cetak laporan: Klik View [Toolbar] $\rightarrow$ Klik Data analysis $\rightarrow$ Print (atau ikon printer).
6.3 Spektrum & Pertindihan (Overlay Signal)
  1. Untuk melihat analisis yang telah dijalankan: Klik RRLC Offline 2x.
  2. Klik File $\rightarrow$ Load Signal $\rightarrow$ Pilih filename yang dikehendaki dan klik OK.
  3. Klik Spectra [Toolbar] $\rightarrow$ Klik Select Peak Spectra (Klik pada mana-mana bahagian peak, imej spectra akan tertera).
  4. Bagi proses overlay standard dan sampel:
    • Klik File $\rightarrow$ Overlay Signal $\rightarrow$ Pilih filename yang dikehendaki $\rightarrow$ Klik OK.
    • Klik ikon “Select a set of a peak” atau klik pada imej sampel (spectra sampel akan terhasil).
    • Tekan secara serentak butang: Ctrl + Alt + klik pada peak standard. Maka imej spectra standard akan bertindih (overlay) dengan spectra sampel.
  5. Untuk cetak laporan spektrum: Klik Report [Toolbar] $\rightarrow$ Print.
6.4 Pencucian Sistem Selepas Digunakan

Setelah selesai ujikaji, pastikan sistem terutamanya column dibersihkan dengan sebaiknya bagi mengelak column tersumbat:

  1. Cuci sistem HPLC dengan fasa gerak 5% Methanol yang telah ditapis dengan membran 0.45 µm selama 1 jam dengan kadar aliran 1.0 mL/min.
  2. Kemudian cuci sistem dengan 100% Acetonitrile atau Methanol (bergantung pada column) yang telah ditapis selama 30 minit dengan kadar aliran 1.0 mL/min untuk penyimpanan kolum.
6.5 Menutup Sistem HPLC
  1. Klik ikon DAD $\rightarrow$ Control $\rightarrow$ UV Lamp $\rightarrow$ Off $\rightarrow$ OK.
  2. Klik ikon Thermostat $\rightarrow$ Control $\rightarrow$ Off $\rightarrow$ OK.
  3. Klik ikon Pump $\rightarrow$ Set up pump $\rightarrow$ Turunkan kadar aliran sedikit demi sedikit sehingga 0.00 mL/min $\rightarrow$ OK.
  4. Klik File $\rightarrow$ Exit $\rightarrow$ Close RRLC Online? $\rightarrow$ Yes.
  5. Switch off LC pump, thermostat and lamp? $\rightarrow$ Yes.
  6. Start menu $\rightarrow$ Shut down computer $\rightarrow$ Yes.
  7. Tutup semua butang suis utama pada sistem HPLC.
