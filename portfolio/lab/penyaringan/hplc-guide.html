Shimadzu Prominence-i HPLC Operating Guide

Standard Operating Procedure: LC-2030C 3D (LabSolutions CS/DB)

Comprehensive step-by-step instrument operation manual: hardware power-up, solvent degassing, Auto Purge, gradient time program configuration, baseline equilibration, batch table sequencing, PDA 3D spectral integration, and post-analysis column flushing.

Software LabSolutions RealTime & PostRun

FASA 1: PERMULAAN

1.0 Tatacara Memulakan Instrumen & Log Masuk Perisian

Ref: PKKK/300/UP/011 Para 6.1
  1. Bekalan Kuasa: Buka semua suis utama (Main power switches) dan hidupkan suis mesin HPLC Shimadzu LC-2030C 3D.
  2. Kata Laluan Mesin: Pada panel hadapan skrin sentuh instrumen, masukkan password: 00000 dan tekan OK.
  3. Pelarut Fasa Bergerak: Pastikan botol pelarut diisi mencukupi dan penuras salur masuk (solvent inlet filter) terendam sepenuhnya di dasar botol tanpa menyentuh dinding. Semua pelarut akueus dan organik MESTI ditapis menggunakan membran 0.45 µm dan dinyahgas (degas) dalam kukus ultrasonik selama 15–20 minit.
  4. Buka Perisian: Pada desktop komputer, klik dua kali ikon LabSolutions.
  5. Log Masuk: Pada paparan User ID, masukkan Admin dan biarkan ruangan Password kosong. Klik OK.
  6. Pilih Instrumen: Dalam tetingkap menu utama, klik Instrument dan seterusnya pilih LC-2030C 3D untuk membuka tetingkap Real Time Analysis.
FASA 2: TETAPAN METHOD

2.0 Konfigurasi Kaedah Pengujian (Method Settings)

Ref: PKKK/300/UP/011 Para 6.1.7 – 6.2.7

Untuk membuka atau membina kaedah pengujian (Method):

• Buka Method Sedia Ada: File $\rightarrow$ Open Method File $\rightarrow$ Pilih kaedah yang dikehendaki.

• Bina Method Baharu: File $\rightarrow$ New Method $\rightarrow$ Method Settings.

1. Pump Settings Mode: Low Pressure Gradient (4 Valve) Tetapkan Total Pump Flow (cth: 0.7–1.0 mL/min), Solvent B Conc, Solvent C Conc mengikut SOP. Tetapkan Pressure Limit (Pmax: 400 bar, Pmin: 0 bar).
2. Column Oven & Autosampler Suhu Oven: 30 °C – 40 °C (NMT 80 °C) Tandakan (✓) pada kotak heating. Tetapkan autosampler temperature (cth: 4 °C jika matriks tidak stabil).
3. PDA Detector Start/End Wavelength: 190 – 400 nm Set Cell Temperature mengikut suhu oven kolum (maksimum 60 °C). Jika tiada oven pemanas, jangan tandakan Cell Temp.
4. LC Time Prog (Gradient) Changeable Gradient Program Isi masa dan % fasa bergerak baris demi baris. Klik 'Draw Curve' untuk semak graf. Pastikan komposisi fasa bergerak pada akhir analisis sama dengan komposisi asal (re-equilibration).
FASA 3: AUTO PURGE & FLUSHING

3.0 Tatacara Auto Purge & Penstabilan Garisan Dasar (Baseline)

Ref: PKKK/300/UP/011 Para 6.2.8, 6.3 & 6.4
  1. Bila Perlu Auto Purge?: Wajib dijalankan setiap kali pelarut ditambah atau ditukar jenis bagi menyingkirkan buih udara dalam talian pam.
  2. Jalankan Auto Purge: Muat turun fail kaedah dengan klik ikon Download $\rightarrow$ Klik ikon Auto Purge. Sistem akan mengepam pada kadar 5.0 mL/min selama 3 minit untuk setiap saluran pelarut. Tunggu sehingga selesai.
  3. Pertukaran Pelarut Berbeza / Buffer: Jika bertukar dari buffer ke organik atau sebaliknya, gunakan pelarut perantaraan (Intermediate: 10% MeOH / 90% Air) terlebih dahulu untuk mengelakkan pemendakan garam buffer.
  4. Mulakan Aliran (Pumping): Klik ikon Instrument ON/OFF. Perhatikan bacaan tekanan (Pressure) pada jadual hujung kanan tetingkap Real Time. Tekanan mestilah stabil (contoh: 120–180 bar).
  5. Penstabilan Suhu (Thermal Equilibration): Pantau paparan suhu ketuhar kolum sehingga mencapai suhu sasaran kaedah (contoh: 40 °C).
  6. Pemerhatian PDA Plot Baseline:
    Klik ikon Plot pada tetingkap Real Time. Alirkan fasa bergerak sekurang-kurangnya 15–30 minit sehingga garisan dasar mendatar dan bacaan tekanan stabil.
    Untuk memilih gelombang paparan: Klik kanan pada ikon PDA Chromatogram $\rightarrow$ Display Settings $\rightarrow$ Masukkan gelombang (contoh: 240 nm atau 280 nm) $\rightarrow$ OK.
    Sebelum memulakan suntikan kelompok, klik butang Stop pada tetingkap Plot.
FASA 4: REAL-TIME BATCH RUN

4.0 Penyediaan Jadual Suntikan Kelompok (Batch Sequence)

Ref: PKKK/300/UP/011 Para 6.4.2
  1. Pada Assistant Bar di sebelah kiri, klik ikon Real Time Batch.
  2. Bagi menambah baris suntikan: Klik kanan pada jadual batch $\rightarrow$ Klik Add Row.
  3. Isikan ruangan parameter:
    • Tray Name: Tray 1 (atau Tray 2).
    • Vial No.: Kedudukan nombor vial pada rak autosampler.
    • Sample Name: Nama unik sampel / standard / blank.
    • Sample Type: Standard / Unknown / Blank.
    • Method File: Nama fail kaedah yang digunakan.
    • Data File Name: Nama unik penyimpanan data kromatogram.
    • Inj Volume: Isipadu suntikan (contoh: 10 µL atau 15 µL).
  4. Simpan jadual batch: File $\rightarrow$ Save Batch File As.
  5. Mulakan suntikan kelompok dengan menekan butang Start Real Time Batch.
FASA 5: PENCUCIAN & SHUTDOWN

5.0 Pencucian Turus (Flushing) & Penutupan Sistem

Ref: PKKK/300/UP/011 Para 6.5
⚠️ PERATURAN PENCUCIAN TURUS TERBALIK (REVERSED-PHASE C18 / PHENYL-HEXYL):
1. Jika Kaedah Menggunakan Fasa Bergerak Berasid / Buffer Garam:
Lakukan flush dengan 90% Air : 10% Methanol selama 30 minit bagi menyingkirkan semua sisa garam. Seterusnya bilas dengan 100% Acetonitrile / Methanol selama 30 minit. Akhir sekali simpan kolum dalam 70% Acetonitrile : 30% Air selama 15 minit.
2. Jika Kaedah Menggunakan Air & Pelarut Organik Sahaja:
Flush terus dengan 100% Acetonitrile selama 30 minit, diikuti 70% Acetonitrile : 30% Air selama 15 minit.

Langkah Penutupan Sistem:

  1. Klik ikon Instrument ON/OFF untuk mematikan pam, pemanas oven, dan lampu DAD/PDA.
  2. Tutup tetingkap Real Time Analysis.
  3. Tutup perisian LabSolutions.
  4. Tutup suis kuasa HPLC jika tiada analisis susulan dirancang pada hari tersebut.
  5. Isi dan tandatangan buku log instrumen (Rekod Penyelenggaraan Alat Shimadzu Prominence-i).
