1.0 SKOP

Prosedur ini hendaklah digunapakai untuk mengendalikan alat Shimadzu HPLC (Prominence-i) bagi ujian penyaringan campurpalsu dalam produk tradisional, suplemen kesihatan dan kosmetik.

2.0 DEFINISI

HPLC: High Performance Liquid Chromatography (Kromatografi Cecair Berprestasi Tinggi).

3.0 CARTA ALIRAN

Tiada carta aliran untuk prosedur ini.

4.0 TANGGUNGJAWAB

4.1 Ketua Unit / Pegawai Farmasi Bertanggungjawab:

Memastikan prosedur ini diikuti semasa pengendalian alat ini.

4.2 Pegawai Farmasi:

a) Menyelia proses pengendalian alat ini oleh Penolong Pegawai Farmasi.
b) Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

4.3 Penolong Pegawai Farmasi U7 / U6:

Memastikan penyelenggaraan alat ini dijalankan pada waktu yang ditetapkan dan menyimpan rekod penyelenggaraan alat.

4.4 Penolong Pegawai Farmasi:

Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

5.0 PROSEDUR
6.1 Tatacara Memulakan LC
  1. Buka semua suis utama bekalan kuasa.
  2. Buka suis mesin HPLC Shimadzu (LC-2030C 3D).
  3. Masukkan password: 00000 dan tekan OK.
  4. Klik ikon “Lab Solution” pada desktop.
  5. Pada paparan, User ID: Admin dan Password dibiarkan kosong. Klik “OK”.
  6. Dalam menu, klik “Instrument” dan seterusnya klik “LC-2030C 3D”.
6.2 Tetapan Kaedah Pengujian (Method Settings)

Buka fail method yang dikehendaki: File > Open Method File.
Jika ingin membuat method baharu: File > New Method > Method Settings.

6.2.1 Pump Settings:

  • Mode: Low Pressure Gradient (Untuk 4 Valve)
  • Isikan Total Pump Flow berdasarkan Method analisis spesifik.
  • Isikan Solvent B Conc, Solvent C Conc, Solvent D Conc berdasarkan Method (Contoh: B Conc 70% MeOH, C Conc 30% H₂O).
  • Isikan Pressure Limit (Pump A) (cth: Pmax 400 bar).

6.2.2 Autosampler Setting: Suhu boleh ditetapkan jika diperlukan (cth: 4 °C).

6.2.3 Column Setting: Tetapkan suhu Oven berdasarkan method yang ditetapkan. Jangan set > 80–85 °C. Tandakan (✓) jika method memerlukan pemanas (heating).

6.2.4 Detector Setting (Menggunakan PDA): Setkan Start Wavelength dan End Wavelength (190–400 nm). Setkan Cell Temperature mengikuti column oven temperature (sekiranya suhu oven > 60 °C, set Cell Temperature sebagai 60 °C; sekiranya column oven tidak digunakan, Cell Temperature tidak perlu ditandakan).

6.2.5 Data Acquisition: Isikan LC stop time analisis dan klik Apply to All acquisition time.

6.2.6 LC Time Prog (Changeable Gradient):

Sekiranya gradient tidak bertukar digunakan, baris pertama sahaja yang diisikan dengan masa sama dengan LC Stop time.
Sekiranya gradient bertukar (changeable gradient) digunakan: Setiap baris menunjukkan satu arahan cara kerja pengubahan mobile phase. Klik “Draw Curve” untuk melukis graf. Setiap kali kaedah changeable gradient digunakan, sistem perlu dikalibrasi balik ke setting pam semasa dimulakan sebelum suntikan kedua dijalankan (contoh: jika awal analisis B=30%, akhir analisis B perlu dikembalikan ke 30% untuk elak sebarang shift dalam retention time).

6.2.8 Auto Purge:

Sistem Auto Purge mengeluarkan buih udara dalam saluran solvent untuk mengelakkan daripada memasuki column. Saluran solvent wajib menjalankan Auto Purge sekiranya: (1) Solvent ditambah ke dalam botol, atau (2) Solvent bertukar jenis.
Jikalau solvent yang perlu ditukar melibatkan Intermediate: Pastikan sistem ditutup dahulu $\rightarrow$ Tunggu Pressure jatuh ke sifar $\rightarrow$ Masukkan pump line ke dalam Intermediate Solution $\rightarrow$ Jalankan Auto Purge $\rightarrow$ Masukkan ke dalam botol solvent dikehendaki dan ulangi Auto Purge. (Activate system after Autopurge tidak ditandakan dalam kes melibatkan Intermediate). Simpan fail method (Save Method File).

6.3 Start Up dan Flushing Sistem untuk Analisis
  1. Buka method file atau create method file baru.
  2. Muat turun method file pada ikon “Download”.
  3. Klik ikon untuk Auto Purge dan tunggu sehingga selesai.
  4. Sekiranya analisis dijalankan menggunakan air dan pelarut organik (MeOH/ACN), sistem boleh flush menggunakan mobile phase analisis tersebut.
  5. Sekiranya mobile phase menggunakan buffer atau pelarut asid, sistem perlu flush menggunakan 90% air (H₂O) dan 10% Methanol (MeOH) terlebih dahulu. Selepas itu, flush semula menggunakan mobile phase analisis.
  6. Hidupkan sistem (mobile phase pumping) dengan klik ikon “Instrument On/Off”. Pastikan bacaan tekanan (Pressure) tertera pada jadual bahagian kanan (jika bacaan 0 menunjukkan sistem tidak berjalan).
6.4 Penstabilan Suhu (Thermal Equilibration) & Pemerhatian PDA Detector
  1. Pantau paparan suhu sehingga suhu mencapai bacaan method yang dimuatkan.
  2. Klik ikon “Plot” pada tetingkap Real Time sekurang-kurangnya dalam tempoh running time kaedah sehingga garisan dasar (baseline) stabil dan tekanan konsisten.
  3. Sebelum memulakan suntikan sampel, klik butang “Stop” untuk menghentikan Plot.
  4. Untuk memerhati gelombang yang dipilih di RealTime: Klik kanan ikon “PDA Chromatogram” $\rightarrow$ “Display Settings” $\rightarrow$ Masukkan gelombang (nm) $\rightarrow$ Klik “OK”.
6.5 Jenis Analisis (Single Run / Real Time Batch Run)

6.5.1 Single Run: Acquisition > Klik “Single Run” pada Assistant Bar sebelah kiri > Isikan data file > Start.

6.5.2 Real Time Batch Run: Main > Klik “Real Time Batch” pada Assistant Bar sebelah kiri > Klik kanan pada batch table > Klik “Add Row”. Isikan Method File, Data File Name, Vial No. dan Tray Name. Simpan batch table dan klik “Start Real Time Batch”.

6.6 Tatacara Penutupan Sistem (System Shutdown)
  1. Jika mobile phase air dan pelarut organik (MeOH/ACN): Flush menggunakan 100% pelarut organik (ACN/MeOH) selama 30 minit untuk membersihkan column, diikuti 60–70% pelarut organik : 40–30% air selama 15 minit dan kemudian disimpan.
  2. Jika buffer atau pelarut asid digunakan: Flush menggunakan 90–95% air dan 10–5% pelarut organik selama 30 minit $\rightarrow$ diikuti 100% pelarut organik selama 30 minit $\rightarrow$ akhir sekali flush 15 minit menggunakan 70–60% pelarut organik dan 30–40% air untuk penyimpanan kolum.
  3. Setelah flush selesai, klik “Instrument ON/OFF” untuk menutup pam dan pemanas.
  4. Tutup perisian RealTime dan perisian LabSolutions.
