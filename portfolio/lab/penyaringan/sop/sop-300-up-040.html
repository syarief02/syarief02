This document is intended to establish a standard operating manual for Gas Chromatography Mass Spectrometer (GCMS) in the laboratory.

◈ 2.0 SCOPE

This guide shall be used for the operation of GCMS Shimadzu QP2010 Ultra

None

◈ 6.0 PROCEDURE

(A) Start up GCMS system

1. Switch on UPS.

Switch on any peripheral or accessory equipment connected to the system, before switching on the main GCMS system.

Switch on any sample pretreatment unit connected to the system before switching on the GCMS system.

Turn on the power to the GC.

Turn on the power to the MS.

Turn on the power to the computer, printer and display.

Double click <GCMS Real Time Analysis> icon.

Click OK when Lab Solutions GCMS Solution prompt appears.

Open the carrier gas cylinder valve to supply carrier gas.

Click the <Vacuum Control> icon on the <Real Time> assistant bar.

Click <Auto Startup>.

When <Completed> is displayed, click <Close>.

Wait for 10 minutes after starting up the vaccum system to check for vaccum leakage.

Click the <Tuning> icon on the <Real Time> assistant bar.

Click the <Peak Monitor View> icon on the <Tuning> assistant bar.

Check for vacuum leaks.

Click <Monitor Group> and select <Water,Air> from the list.

Click <Filament On/Off> to turn on the filament. Peaks will be displayed In three windows.

Change the detector voltage gradually so that the peak height for m/z 18 (water) corresponds to half the height of display window.

Compare the peak height for m/z 18 (water) and m/z 28 (nitrogen). Check that the peak height for m/z 28 (nitrogen) is not more than twice that for m/z 18 (water).

Click <Filament On/Off> to turn off filament.

Close <Tuning> window.

Click the <Top> icon on the assistant bar.

(B) Execute Autotuning

Wait for approximately 2 hours (before starting qualitative analysis) or 4 hours (before starting quantitative analysis) after starting up the vacuum system and then perform autotuning.

Click <Tuning> icon on the <Real Time> assistant bar.

Click the <Peak Monitor View> icon on the <Tuning> assistant bar.

Select <New Tuning File> on the <File> menu.

Select the filament to be used.

Click <Start Auto Tuning> icon on the <Tuning> assistant bar.

Enter a file name and click <Save>.

Autotuning starts. When Autotuning is completed, a report is printed.

Click <Save> on the toolbar.

(C) Qualitative Analysis

Start up the <GCMS Real Time Analysis> program.

Click the <Data Acquisition> icon on the <Real Time> assistant bar.

Select <New Method File> on the <File> menu.

Click the <Sampler> tab and specify the number of rinses appropriate for the sample.

Click the <GC> tab and set the analysis conditions.

Click the <MS> tab and set the analysis conditions.

Select <Qualitative Parameters> on the <Method> menu.

Click the <Similarity Search> tab and set the search conditions.

Select <Save Method File As> on the <File> menu.

Enter a file name and click <Save>.

To run a sample, click the <Data Acquisition> icon on the <Real Time> assistant bar.

Load a Method File and execute autotuning.

Click the <Sample Login> icon on the <Acquisition> assistant bar.

Key in the following :

Sample Name

Sample ID

Data File

Vial #

Injection Volume

Load Tuning File

Click OK

Click <Download> icon on the <Acquisition> assistant bar.

To analyse the data :

Double click the <GCMS Postrun Analysis> icon.

Click the <Qualitative> icon on the <Postrun> assistant bar.

Double click the data file to analyse.

Specify a range to be enlarged in the chromatogram by dragging the mouse.

Move the mouse pointer to the peak top and double click.

To substract the background, click <Spectrum Subtraction> on the toolbar. Double click at the background processing position (red arrow shown).

Click the <Similarity Search> icon on the <Qualitative> assistant bar.

Check the similarity search results displayed. Select the checkbox for the applicable compound to enter in the spectrum. Click <Register Spectrum Table>.

Repeat step (iv) to (viii) for other target compounds.

Click the <Qualitative Table> icon on the <Qualitative> assistant bar.

Double click <Done> in the first row of the spectrum process table. <Similarity Search Result> window opens.

Select the box for the applicable compound to enter a compound name in spectrum table

Click <Copy marked compound name to the Spectrum Process Table>.

Repeat step (xi) to (xiii) to search results of all target compounds.

Close the <Qualitative Table> window and click <Save> on the toolbar.

Click <Report Format> icon on the <Postrun> assistant bar.

Click the <New> icon. Select the report template needed.

Click the <Data> tab under the <Data Explorer> window.

Select the data to be printed out and drag it into the report template.

Click <Print>.

(D) Quantitative Analysis

Register the retention times and mass spectra of the target compounds in the spectrum table process based on the Qualitative Analysis done earlier.

Click <Compound Table> icon on the <Postrun> assistant bar.

From Data Explorer, double click the data file in which the spectrum process table for the target compounds was saved.

Click the <Wizard(New)> icon on the <Compound Table> assistant bar.

Select <Use current Spectrum Process Table> and then click <Next>.

Click <Next>.

Select a row in the table, check the mass spectrum for each compound and click <Next>.

Specify the calibration curve type, the quantitative method and other parameters required and click <Next>.

Make the appropriate settings for concentrations and measurement ions and click <Next>.

Set the type, compound name, target ion and reference ion for each substance. After entering the required information for all the compounds, click <Next>.

Click <Finish>.

Click the <Save Compound Table> icon on the <Compound Table> assistant bar.

Click <Save>.

Click the <Create SIM Table[COAST]> icon on the <Compound Table> assistant bar.

Enter a file name and click <Save>.

Maximise the <Creation of Automatic SIM Table[COAST] window.

Select <SIM> and click <Update SIM Table>.

A SIM Table is created automatically. Check the chromatogram and the SIM table and if no changes are required, click <OK>.

Start the <GCMS Real Time Analysis> program and click the <Batch Processing> icon on the <Real Time> assistant bar.

Select <New Batch File> on the <File> menu.

Click the <Wizard> icon on the <Batch> assistant bar.

Create a batch table by keying in the following :

Select <Standard & Unknown>

Specify the method file to be used

Select <Quantitative>

Click <Next>

Vial#

Injection Volume

Average Count

Click <Next>

Data File Name

Click <Next>

Vial#

Sample Count

Injection Volume

Click <Next>

Data File Name

Click <Finish>

Select <Save Batch File As> on the <File> menu

Open the folder where the method file is saved, enter a name and save the file

Set the syringe rinse solvent and samples in the autosampler

Click the <Start> icon on the <Batch> assistant bar.

To analyse the data :

Start the <GCMS Postrun Analysis> program and click the <Calibration Curve> icon on the <Postrun> assistant bar.

Open the method file used in analysis from Data Explorer

Drag and drop the result data according to the calibration levels and a line is plotted

Select a compound in the compound table and click the calibration curve level

Only after correcting the calibration curves, click <Save> on the toolbar to save the method file

Click <Report Format> icon on the <Postrun> assistant bar.

Click the <New> icon. Select the report template needed.

Click the <Data> tab under the <Data Explorer> window.

Select the data to be printed out and drag it into the report template.

Click <Print>.

(E) Shutting Down GCMS

Click the <Vacuum Control> icon on the <Real Time> assistant bar.

Click <Auto Shutdown>.

When <Completed> is displayed, click <Close>.

Quit the <GCMS Real Time Analysis> program and all other programs that are running.

Turn off the power to the computer, printer and display.

Turn off the power to the MS unit.

Turn off the power to the GC unit.

Turn off the accessory/peripheral equipment.

Performance Check

Performance Check will be carried out at each analysis to ensure the sensitivity for the instrument is always at its optimum level. It is carried out by performing Autotuning and the parameters below must be fulfilled :

FWHM value within the range 0.5 to 0.7

Detector voltage < 2 kV

Relative Intensity Ratio for m/z 502 > 2%

Peak Intensity for m/z 69 is at least 2 times in comparison to m/z 28
