PURPOSE

This document is intended to establish a standard operating manual for High Performance Liquid Chromatography (HPLC) in the laboratory.

SCOPE

This guide shall be used for the operation of HPLC Agilent

DEFINITION

HPLC – High Performance Liquid Chromatography

FLOWCHART

None

RESPONSIBILITIES

PROCEDURE

6.1

General Operation of HPLC System H

(For Identification and Quantitation Using SPD-M20A Diode Array Detector and Low Pressure Gradient HPLC)

Power on each Agilent HPLC (binary pump, vacuum degasser, auto sampler, column compartment, diode array detector).

Turn on the computer. Key in the default user name (Admin) and password (3000hanover).

From the Start Menu, select All Programs, Agilent Chemstation, and Instrument 1 Online. Or double click the Instrument 1 on the desktop.

Install required column. Prepare the mobile phases A and B and place the respective suction filter line into the reservoirs.

Purge the two line by :

Open the purge valve located on the pump module by turning the knob counter clockwise several turns.

Click on the pump in the system diagram, then click ‘Set Up Pump’. Set 50% for channel A and B at 5 ml/min for several minutes. Turn on the pump.

After purging, turn off the pump. Close the purge valve.

Creating the method.

From the ‘Method’ menu, select ‘Edit Entire Method’.

Set the required composition and flow rate as stated in protocol. (Try to increase the flow in stages). If gradient run required for your analysis, select the ‘Insert’ button from the ‘Time Table’ group. Click ‘OK’.

Set the column compartment temperature and click ‘OK’.

Fill in the Diod Array Detector signal.

Make sure the UV and Visible lamps are turn on and select the prerun autobalance option is active.

If running cosmetics samples for identification of tretinoin and hydroquinone, select acquisition of all spectra using the full spectral range of 190-950 nm and peak width that corresponds to one spectra every 0.1 seconds.

Click ‘OK’ the DAD signal window.

Tick the ‘Data Acquisition’ and ‘Standard Data Analysis’ to execute at the run time.

From the ‘Method’ menu, select ‘Save Method As’, key in a filename. OK

Turn on the instrument.

Run Method (Single Run)

To inject an individual sample, click ‘Run Control’, select ‘Sample Info’ and fill in the “Operator Name”, ‘Subdirectory”, “Location of the Vial”, “Sample Name” and “Injection Volume”

Click “Run Method”.

Run Method (Sequence Run)

Under Sequence menu, select Sequence Parameters. Create Subdirectory. Select Auto for the data file naming system.

Under Sequence menu, select New Sequence. Fill in the Sequence Table and Save.

Click “Run Sequence”.

Data Analysis (Integration)

Open an Offline Session of the Agilent Chemstation. Go to Data Analysis View.

Click File Menu and Load signal.

To Auto Integrate, click “Integration Menu” and then click “Auto Integrate”. Auto Integration will display the defaults event.

Click on the “Integration Menu” and click “Edit Integration Events”. Set the “Slope”, “Area Reject” and etc. Click “Integrate” icon to view the result.

Click the icon “Exit and Save Event to the Method”.

To name the peaks, select the “Calibration Menu”, choose “New Calibration Table”, click “Ok”. Key in the compound name and then click “Ok”. Click “No” for “Delete lines with zero amounts?”.

Choose “Graphics Menu” and select “Signal Option”. Tick “Axes”, “Baseline”, “Tick Marks”, “Compounds Name” and “Retention Times”. Click “Ok”. Signal option is used to define a look of chromatogram when it is produced on the screen or the printer.

To print the result.

Select the “Report Menu” and click “Specify Report”. Choose “Report Style” and click “Ok”.

Select the “Report Menu”, click “Print Report” and click “Print”.

On completion of analysis.

Change Channel A from mobile phase to 5% Methanol and Channel B to 100% Methanol.

Purge the two line by :

Open the purge valve located on the pump module by turning the knob counter clockwise several turns.

Click on the pump in the system diagram, then click ‘Set Up Pump’. Set 50% for channel A and B at 5 ml/min for several minutes. Turn on the pump.

After purging, turn off the pump. Close the purge valve.

Flush the reverse phase column with 5% Methanol for about 30 minutes followed by Methanol for another 30 minutes at flow rate 1 ml/min.

Flush the normal phase column with iso- propanol for about 30 minutes followed by Methanol for another 30 minutes at flow rate 1 ml/min.

Flush other type columns by following the instructions supplied with the column from manufacturer.

Shutdown the system by selecting “Instrument Menu” and click “System Off”. Power on each Agilent HPLC (binary pump, vacuum degasser, auto sampler, column compartment, diode array detector).

Precautions

Flush the flow line and column with isopropanol before the new mobile phase which is immiscible with the old mobile phase or solvent is pumped through the system.

Flush the flow line and column with 5% Methanol before the buffer solution mobile phase is pumped through the system.

6.2 Performance Check

Performance Check will be carried out in every analysis to ensure the sensitivity for the instrument is always at its optimum level. It is carried out by performing the System Suitability Test using the Standard solution/ Mix Standard Solution and to ensure that the parameters below are fulfilled:

Tailing factor < 2.0

Theoretical plates > 1500
