TUJUAN

Untuk memastikan langkah-langkah yang terlibat dalam proses pengendalian alat Shimadzu High Performance Liquid Chromatography Mass Spectrometer (LCMS-8045) untuk ujian penyaringan campurpalsu dijalankan dengan betul dan berkesan.

SKOP

Prosedur ini hendaklah digunakapakai untuk mengendalikan alat Shimadzu High Performance Liquid Chromatography Mass Spectrometer (LCMS-8045) bagi ujian penyaringan campurpalsu.

DEFINISI

LCMS - Liquid Chromatography Mass Spectrometry

LC - Liquid Chromatography

MS - Mass Spectrometry

CARTA ALIRAN

Tiada carta aliran untuk prosedur ini.

TANGGUNGJAWAB

Ketua Unit / Pegawai Farmasi Bertanggungjawab

Memastikan prosedur ini diikuti semasa pengendalian alat ini.

Pegawai Farmasi

Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

Menyelia proses pengendalian alat ini oleh Penolong Pegawai Farmasi.

5.3 Penolong Pegawai Farmasi U7 / U6

Memastikan penyelenggaraan alat ini dijalankan pada waktu yang ditetapkan dan menyimpan rekod penyelenggaraan alat.

5.4 Penolong Pegawai Farmasi

Mengendalikan alat ini mengikut prosedur yang telah ditetapkan.

PROSEDUR

6.1 Startup
6.1.1 HidupkanLC dan MS.
6.1.2 Pastikanterdapataliran gas nitrogen dan argon ke MS.

Buka pintu MS dan keluarkan DL plug.

Tutup kembali pintu MS.

6.1.3 Hidupkan computer dan mesin pencetak.
6.1.4 Pastikanikon[LabSolution Service]pada Taskbar berwarna hijau.
6.1.5 Klik 2x padaikon.
6.1.6 Pada window Log in, masukkan user id sebagai “admin”, kosongkan pada password dan klik ok.
6.1.7 Mulakan program [Realtime Analysis]. Klik1x pada Instrument dan klik 2x pada LCMS-Instrument 1.
6.1.8 Kemudian pada window [RealTime Analysis], klik [Data Acquisition]. Pastikan status alat adalah Ready untuk semua komponen LCdanMS.
6.1.9 Masukkan column pada column oven.
6.1.10 Untuk menghasilkan method baru:

Klik ikon new pada Toolbar.

6.1.11 Tentukan tatacara yang ingin dijalankan.
6.3 Method setting (LC)
6.3.1 Pump (Low Pressure Gradient System)

Pada Instrument Parameter view, klik Advanced.

Pilih mode : Low Pressure Gradient

Masukkan parameter mengikut tatacara dan column yang digunakan:

Total Pump A flow

Concentration of Solvent B, C, D

Pressure Limit (Pump A)

6.3.2 Autosampler

Pastikan parameter adalah sebagai berikut:

Sample Rack: Rack 1.5ml 70 vials

Rinse Mode: Before and after aspiration

6.3.3 Column

Klik pada Column oven.Pastikan pada suhu 40°C.

6.3.4 LC Time Program

Masukkan system gradient atau isocratic berdasarkan tatacara yang akan digunakan.

6.3.5 Data Acquisition

Masukkan masa pada LC stop time berdasarkan end gradient time yang telah ditetapkan pada 6.3.4.

Kemudian klik Apply to All acquisition time.

6.4 Method Setting (MS)
6.4.1 Interface

Masukkan parameter sebagai berikut (default setting):

Nebulizing gas flow: 3 L/min

DL temperature 250°C

Heat block temperature: 400°C

6.4.2 MS

Q3 scan.Klik Scan (+), dijalankan tanpa CID gas.

Tetapkan range m/z dan masukkan 0.2 sec pada event time.

Product ion scan. Klik Product Ion Scan (+) atau (-). Dijalankan bersama CID gas. Tetapkan range m/z, purcursor ion dan masukkan 0.2 sec pada event time.

Product ion scan (multiple compound)

Klik Product Ion Scan (+) atau (-).Dijalankan bersama CID gas. Tetapkan range m/z, purcursor ion dan masukkan 0.2 sec pada event time.

Neutral Loss

Klik Product Ion Scan (+) atau (-).Dijalankan bersama CID gas.Tetapkan range m/z, neutral ion dan masukkan 0.2 sec pada event time

6.5 Method yang telah ditetapkan di simpan dan klik download. MS akan hidup secara automatic.
6.6 Pada alat LC, klik ikon Pump, putar kan drain valve dan klik purge pada alat LC.
6.7 Tunggu sehingga heater, drying gas dan nebulizing gas stabil.
6.8 Kemudian klik ikon Instrument On/Off.
6.9 Flush selama 10 – 15 minit. Kemudian klik ikon IG dan MS.
6.10 Mulakan analisis sampel.
6.11 Single analysis run

Pada Assistant Bar di Data Acquisition, klik Single analysis run.

Pada window Single Run, masukkan informasi sampel di Sample Name, Sample ID, Data File, Method file, Vial, Tray, Injection volume,dan Tuning file.

Klik ok.Analisis dimulakan.

6.12 Batch Run

Pada Assistant Bar, klik RealTime Batch.

Klik View pada Toolbar. Kemudian klik Table easy setting.

Masukkan informasi batch sampel.

Klik ok.

Tampilan Batch Table adalah seperti berikut:

Simpan Batch Table.

Klik Start. Analisis dimulakan.

6.13 Daily shutdown LCMS

Klik kembali ikon Instrument On/Off untuk menghentikan aliran mobile phase,

Tutup semua window atau klik File dan Exit.

Tutupkan HPLC modules dengan klik pada Power. DILARANG MENUTUP VACUUM LCMS
