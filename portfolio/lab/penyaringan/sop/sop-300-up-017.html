⚡ Panduan Khas Pengendalian & Penyelenggaraan Terperinci (Pro Tips):
  • 🎯 **Tuning Harian MS**: Jalankan `s.tune` (Standard Tune) atau `a.tune` setiap pagi dan simpan laporan penalaan rasmi.
  • 💧 **Air/Water Check**: Pastikan $m/z\ 18$ (Air) $< 10\%$ dan $m/z\ 28$ ($N_2$) $< 5\%$ berbanding $m/z\ 69$.
  • 🌡️ **Suhu Antaramuka & Sumber EI**: EI Source $230\ ^\circ\text{C}$, Transfer Line / Interface $240\ ^\circ\text{C}$, Inlet $250\ ^\circ\text{C}$.
  • ⏱️ **Solvent Delay**: Tetapkan Solvent Delay $4.00\text{ min}$ bagi melindungi filamen MS daripada beban pelarut Methanol yang pekat.
  • 📊 **SIM Integration**: Kuantitasi menggunakan Target Ion utama ($m/z\ 31$ bagi EG, $m/z\ 45$ bagi DEG) dan sahkan dengan Qualifier Ions mengikut Had Toleransi Table 6.
💡 Petua & Perhatian Penting Makmal (Bench Notes):
  • Lakukan Standard Spectra Tune (s.tune) atau Autotune (a.tune) setiap hari sebelum analisis dan pastikan laporan LULUS.
  • Semak paras kebocoran udara/air (Air/Water Check): m/z 18 < 10% dan m/z 28 < 5% berbanding puncak dasar m/z 69.
  • Gunakan pelarut berkualiti kromatografi gas dan pastikan septum suntikan ditukar berkala bagi mengelak 'ghost peaks'.

TUJUAN

Untuk memastikan langkah-langkah yang terlibat dalam proses pengendalian dan penyelenggaraan alat Gas Chromatography Mass Spectroscopy Agilent (8890/5977B) semasa pengujian produk tradisional, suplemen kesihatan dan kosmetik untuk tujuan penyaringan dijalankan dengan betul dan berkesan.

SKOP

Prosedur ini hendaklah digunakapakai untuk mengendalikan alat GCMS (8890/5977B) bagi pengujian semua produk tradisional, suplemen kesihatan dan kosmetik.

DEFINISI

GCMS - Gas Chromatography Mass Spectroscopy

TIC - Total Ion Current

RTE - RunTime Environment

PROSEDUR

Buka PC

Klik 2X ikon

Paparan di bawah akan muncul di skrin komputer.

Pilih Method yang ingin digunakan –

Untuk menghasilkan tatacara pengujian baru, ikut langkah-langkah berikut:

Pilih Method dan klik Load Method. Kemudian pilih method yang ingin diubah (contoh: default.m). Seterusnya klik Save Method As… dan masukkan nama tatacara yang baru dan fail tersebut akan disimpan.

Klik Method dan pilih Edit Entire Method

Pilih bahagian yang ingin diubah (method information, instrument/acquisition atau data analysis)

Pilih Method dan klik Save. tatacara baru akan disimpan dengan parameter baru yang telah ditetapkan (contoh: Testing Method Latest.m)

Untuk jalankan sampel:

Pastikan tuning dilakukan setiap hari sebelum sampel pertama hendak dijalankan pada hari tersebut dan pastikan laporan adalah lulus.

Pilih icon View > Tune dan Vacuum Control.

Pilih Standard Spectra Tune (s.tune) atau Autotune (a.tune).

Setelah selesai Standard Spectra Tune (s.tune) atau Autotune (a.tune), teruskan dengan Tune Evaluation.

Tunggu seketika sehingga laporan dicetak.

Pastikan data s.tune atau a.tune yang terbaru telah disimpan.

.

Pilih icon View > Instrument Control untuk jalankan analisis.

Sampel Single Run:

Pastikan sampel telah dilarutkan dengan pelarut sesuai dan telah ditapis menggunakan penapis 0.45µm ke dalam vial.

Letak vial di tempatnya dan pastikan nombor kedudukan vial di mana ia diletakkan.

Kemudian pilih Sequence dan klik New Sequence.

Masukkan data-data yang diperlukan seperti Sample Name, Vial No, Method Path, Method File, Data File dan Comment (sekiranya ada). Semak semula data yang telah dimasukkan dan klik Run Sequence untuk mulakan injeksi sampel.

Sampel Batch Run:

Jika sampel yang ingin diuji adalah banyak, pengujian sampel boleh dijalankan secara batch sequence / sequence table:

Pilih Sequence dan klik Edit Sequence.

Isi maklumat sampel yang diperlukan dalam setiap ruangan column:

Vial – Nombor sampel di dalam tray vial (No. 1-150)

Name - Nama sampel seperti dalam worksheet

Method path - Folder tatacara pengujian yang dijalankan

Method file - Tatacara pengujian yang dijalankan

Data path - Folder penyimpanan data pengujian

Data file – Nama yang unik untuk setiap sample injection

Comment – Rumusan data bagi sample injection tersebut

Tambah barisan untuk setiap sample injection berlainan.

Setelah semua data sampel diisi, klik Run Sequence.

Isi maklumat pada Operator name dan pastikan maklumat data file directory dan data path dalam sequence table adalah sama.

Klik Run Sequnce sekiranya semua maklumat yang diisi telah disemak dan tepat.

Setelah sampel selesai analisis, kromatogram yang diperolehi perlu dianalisis untuk mendapatkan maklumat tertentu terutamanya mass spectrum dan identiti sampel tersebut. Data Analisis perlu dijalankan seperti di bawah:

Pilih ikon GCMS Data Analysis.

Pilih File > klik Data File berdasarkan Data Path yang diisi semasa Single Run/ Batch File dijalankan.

Kemudian pilih Data File yang diingini. Klik OK.

Pilih peak yang ingin dianalisis (window TIC). Tukar skala jika ingin besar/kecilkan peak:

Pilih Chromatogram > klik Chromatogram Scaling.

Pilih Total Ion Current dan klik OK.

Kemudian pilih Enter Absolute Y-axis value, klik OK.

Masukkan nilai paksi-Y yang diingini dan klik OK > Done.

Pilih Select Integrator untuk chromatogram > Chemstation Intergrator/ RTE Intergrator.

Klik Auto Integrate. Maklumat retention time akan terpapar pada setiap peak yang berjaya di integrasikan.

Klik Spectrum > Library Search Report untuk menjana laporan sebatian (compound) bagi setiap integrated peak dalam kromatogram.

Kromatogram dan Library Search Report perlu dicetak dan disertakan dalam laporan sekiranya kromatogram tidak dikesan bahan terkawal atau larangan.

Untuk mencetak laporan Library Search Report, pilih File > Print> Selected Window.

Kromatogram bertanda sebatian yang dijumpai, Similariy Search dan Mass Spectrum perlu dicetak sekiranya sampel dikesan bahan kawalan atau larangan.

Untuk cetak Mass Spectrum:

Buatkan kotak dalam peak tersebut dengan klik kanan (tanpa lepas).

Klik kiri 2 kali pada window spektrum bawah spektrum untuk dapatkan jisim spektrum (mass spectrum) bagi peak tersebut yang sepadan dengan mass spectrum library.

Klik Print pada paparan di skrin.

Untuk cetak laporan Similarity Search:

Klik butang Statistik pada paparan di atas.

Paparan akan bertukar seperti di bawah pada skrin komputer.

Tekan butang Print untuk cetak laporan.

Untuk label peak dengan nama bahan sebatian:

Halakan kursor pada peak yang dipilih.

Klik kiri dan kanan serentak pada tetikus.

Isi nama sebatian dan peratusan persamaan (similarity percentage) pada ruangan Text.

Tekan add dan nama sebatian akan dipaparkan pada peak yang dipilih.

Untuk cetak kromatogram yang telah dilabel:

Klik File > Print > Selected Window (2: TIC).
