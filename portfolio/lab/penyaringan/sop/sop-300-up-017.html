⚡ Panduan Khas Pengendalian & Penyelenggaraan Terperinci (Pro Tips):
  • 🎯 **Tuning Harian MS**: Jalankan `s.tune` (Standard Tune) atau `a.tune` setiap pagi dan simpan laporan penalaan rasmi.
  • 💧 **Air/Water Check**: Pastikan m/z 18 (Air) < 10% dan m/z 28 (N₂) < 5% berbanding m/z 69.
  • 🌡️ **Suhu Antaramuka & Sumber EI**: EI Source 230 °C, Transfer Line / Interface 240 °C, Inlet 250 °C.
  • ⏱️ **Solvent Delay**: Tetapkan Solvent Delay 4.00 min bagi melindungi filamen MS daripada beban pelarut Methanol yang pekat.
  • 📊 **SIM Integration**: Kuantitasi menggunakan Target Ion utama (m/z 31 bagi EG, m/z 45 bagi DEG) dan sahkan dengan Qualifier Ions mengikut Had Toleransi Table 6.
💡 Petua & Perhatian Penting Makmal (Bench Notes):
  • Lakukan Standard Spectra Tune (s.tune) atau Autotune (a.tune) setiap hari sebelum analisis dan pastikan laporan LULUS.
  • Semak paras kebocoran udara/air (Air/Water Check): m/z 18 < 10% dan m/z 28 < 5% berbanding puncak dasar m/z 69.
  • Gunakan pelarut berkualiti kromatografi gas dan pastikan septum suntikan ditukar berkala bagi mengelak 'ghost peaks'.

6.0 PROSEDUR

Buka PC

Paparan di bawah akan muncul di skrin komputer.

Untuk menghasilkan tatacara pengujian baru, ikut langkah-langkah berikut:

Untuk jalankan sampel:

Setelah selesai Standard Spectra Tune (s.tune) atau Autotune (a.tune), teruskan dengan Tune Evaluation.

.

Sampel Single Run:

Kemudian pilih Sequence dan klik New Sequence.

Sampel Batch Run:

Jika sampel yang ingin diuji adalah banyak, pengujian sampel boleh dijalankan secara batch sequence / sequence table:

Isi maklumat sampel yang diperlukan dalam setiap ruangan column:

Vial – Nombor sampel di dalam tray vial (No. 1-150)

Name - Nama sampel seperti dalam worksheet

Method path - Folder tatacara pengujian yang dijalankan

Method file - Tatacara pengujian yang dijalankan

Data path - Folder penyimpanan data pengujian

Data file – Nama yang unik untuk setiap sample injection

Comment – Rumusan data bagi sample injection tersebut

Tambah barisan untuk setiap sample injection berlainan.

Setelah semua data sampel diisi, klik Run Sequence.

Isi maklumat pada Operator name dan pastikan maklumat data file directory dan data path dalam sequence table adalah sama.

Setelah sampel selesai analisis, kromatogram yang diperolehi perlu dianalisis untuk mendapatkan maklumat tertentu terutamanya mass spectrum dan identiti sampel tersebut. Data Analisis perlu dijalankan seperti di bawah:

Kemudian pilih Data File yang diingini. Klik OK.

Kemudian pilih Enter Absolute Y-axis value, klik OK.

Kromatogram dan Library Search Report perlu dicetak dan disertakan dalam laporan sekiranya kromatogram tidak dikesan bahan terkawal atau larangan.

Untuk mencetak laporan Library Search Report, pilih File > Print> Selected Window.

Kromatogram bertanda sebatian yang dijumpai, Similariy Search dan Mass Spectrum perlu dicetak sekiranya sampel dikesan bahan kawalan atau larangan.

Untuk cetak Mass Spectrum:

Buatkan kotak dalam peak tersebut dengan klik kanan (tanpa lepas).

Untuk cetak laporan Similarity Search:

Paparan akan bertukar seperti di bawah pada skrin komputer.

Untuk label peak dengan nama bahan sebatian:

Halakan kursor pada peak yang dipilih.

Isi nama sebatian dan peratusan persamaan (similarity percentage) pada ruangan Text.
