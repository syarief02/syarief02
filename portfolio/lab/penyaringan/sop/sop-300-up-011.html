TUJUAN

Untuk memastikan langkah-langkah yang terlibat dalam proses pengendalian alat Shimadzu High Performance Liquid Chromatography (Prominence-i) untuk ujian penyaringan campurpalsu dijalankan dengan betul dan selamat.

SKOP

Prosedur ini hendaklah digunapakai untuk mengendalikan alat Shimadzu HPLC (Prominence-i) bagi ujian penyaringan campurpalsu.

PROSEDUR

Buka semua suis utama

Buka suis mesin HPLC.

Masukkan password (00000) – OK

Klik ikon “Lab Solution”.

Paparan User ID: Admin dan Password dibiarkan kosong. Klik “OK”.

Dalam menu, klik “Instrument” dan seterusnya “LC-2030C 3D”.

Method Settings

Buka fail method yang dihendaki.

File > Open Method File

Jika ingin membuat method yang baru:

File > New Method> Method Settings

Pump Settings

Mode: Low Pressure Gradient (Untuk 4 Valve)

Isikan:

Total Pump Flow : Berdasarkan Method

Solvent B Conc; Solvent C Conc; Solvent D conc : Berdasarkan Method:

Contoh : B Conc 70% MEOH ; C Conc 30% H20

Isikan Pressure Limit (Pump A)

Autosampler Setting

▹ *Suhu boleh ditetapkan jika diperlukan

Column Setting

Tetapkan suhu Oven berdasarkan method yang ditetapkan.

Jangan set > 80-85°C

Tandakan (/) jika method memerlukan pemanas (heating).

Detector Setting (Menggunakan PDA)

Setkan Start Wavelength dan End Wavelength berdasarkan method.

Setkan Cell Temperature – mengikuti column oven temperature.

Sekiranya column oven temperature > 60°C, set Cell Temperature sebagai 60°C

Sekiranya column oven tidak digunakan, Cell Temperature tidak perlu ditandakan.

Data Acquisition

Isikan LC stop time analisis dan klik Apply to All acquisition time.

Jika stop time tidak diketahui, biarkan dalam keadaan Default.

Pengguna akan mengetahui end time lepas elution time bagi peak.

LC Time Prog.

Sekiraya gradient tidak bertukar (changeable gradient) tidak digunakan, baris pertama sahaja yang diisikan.

Masa (time) adalah sama dengan LC Stop time berdasarkan setting Data Aquisitition 6.1.12.

Sekiranya gradient bertukar (changeable gradient) digunakan:

Setiap baris adalah menunjukkan satu arahan cara kerja.

Kesemua baris mengarahkan pengubahan mobile phase yang boleh diterangkan dengan melukis graf dengan klik pada “Draw Curve”.

Setiap kali kaedah changeable gradient digunakan, sistem perlu dikalibrasi balik ke setting pam semasa dimulakan sebelum suntikan kedua dijalankan.

Ini adalah untuk memastikan tiada shift dalam retention time.

Sebagai contoh, jika method menyatakan Composition B= 30% pada awal analisis, Compositon B pada akhir analisis perlu dikekalkan 30%.

Sistem Auto Purge boleh mengeluarkan buih udara dalam saluran solvent untuk mengelakkan daripada memasuki column.

Saluran solvent perlu menjalankan Auto Purge sekiranya:

Solvent ditambah ke dalam botol solvent.

Solvent bertukar jenis.

Ini adalah untuk memastikan tiada kontaminasi solvent dengan cecair akueus.

Jikalau solvent yang perlu ditukar melibatkan Intermediate:

Pastikan sistem ditutup dahulu.

Tunggu Pressure jatuh ke sifar.

Keluarkan pump line yang betul dan masukkan ke dalam Intermediate Solution.

Jalankan purging seperti yang dijelaskan dalam setting Auto Purge 6.2.8.

Setelah itu, keluarkan pump line dan masukkan dalam botol cecair (solution bottle) yang dikehendaki dan ulangi kaedah purging (rujuk Auto Purge 6.2.8)

Activate system after Autopurge tidak ditandakan dalam kes melibatkan Intermediate. Selepas method Auto Purge ditetapkan, Fail method disimpan (Save Method File).

Bagi memastikan sistem sedang berjalan:

Real Time Window ; hujung bahagian kanan ; kelihatan jadual tertera seperti di bawah.

Jika mobile phase sedang pump, bacaan tekanan (Pressure) akan tertera pada jadual.

Contohnya di B Conc dengan bacaan 2 bar. Sekiranya bacaan tekanan (Pressure) ialah sifar “0” menunjukkan sistem tidak berjalan.

6.4. Penstabilan Suhu (Thermal Equilibration)

Sebelum suntikan dijalankan, butang “Stop” diklik untuk memastikan “Plot” dihentikan.

PDA memberi pilihan kepada pengguna semasa membuat suntikan untuk memilih gelombang (wavelength) yang diingini ; bagi memerhati gelombang yang dipilih di “ RealTime”; sila ikut prosedur di bawah:

Klik kanan pada ikon “PDA chromatogram”

Pilih “ Display Settings”

Masukkan gelombang (wavelength) yang perlu diperhatikan.

Klik “OK”.

Chromatogram untuk gelombang yang dipilih kini boleh diperhatikan.

▹ b) Main > klik “Real Time Batch” pada Assistant Bar di bahagian kiri.
▹ c) Bagi menambah baris dalam batch table > Klik kanan pada batch table > klik > Add Row

Simpan batch table setelah selesai diisi dan klik “Start Real Time Batch”.
