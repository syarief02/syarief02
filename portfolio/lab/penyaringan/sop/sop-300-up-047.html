1.0 OBJECTIVE

◼ To screen for theophylline & caffeine present in cosmetic samples using GCMS.

📐

2.0 SCOPE

◼ This test method is only to be used for identification of theophylline & caffeine in cosmetic products.

6.0 PROCEDURE

◼ GCMS – QP 2010

GC Column : Rxi – 5Sil MS 30m x 250mm x 0.25µm

◼ Ultrasonic bath

◼ Glass stoppered conical flasks

◼ Volumetric flask (20 mL)

◼ Glass fiber filter paper (125 mm)

◼ GC autosampler vial

◼ Ethanol

◼ Theophylline Reference Standard

Caffeine Reference Standard

Test Method

Standard preparation

Reference solution: 0.1 mg/mL of Theophylline and Caffeine in Ethanol.

Accurately weigh 2.0 mg of Theophylline Reference Standard and Caffeine reference standard and put it in a 20 mL volumetric flask. Make up to volume with Ethanol.

Note: The weight of reference standard can be modified to minimize the usage of the reference standard.

Sample preparation

Use the filtrate for GCMS injection

Chromatographic Conditions

GCMS Conditions:

Mode : EI

Injection volume : 1 μL

Split ratio : 10:1

Column flow : 1.0mL/min

Inlet temperature : 250°C

Interface temperature : 280°C

MS Quad temperature : 150°C

MS source temperature : 230°C

Oven temperature:
