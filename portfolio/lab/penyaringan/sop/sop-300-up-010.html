TUJUAN

Untuk memastikan langkah-langkah yang terlibat dalam proses pengendalian alat Gas Chromatography Mass Spectrometer Shimadzu (QP2010 Ultra) untuk ujian penyaringan campurpalsu untuk ujian penyaringan (kualitatif) dan analisis penentuan kandungan (kuantitatif) secara sistematik bagi memastikan keputusan ujian yang tepat dan berkesan.

SKOP

Prosedur ini merangkumi pengendalian alat Gas Chromatography Mass Spectrometer Shimadzu (QP2010 Ultra) untuk ujian penyaringan (kualitatif) dan analisis penentuan kandungan (kuantitatif) melibatkan produk farmaseutikal, ubat tradisional, kosmetik, serta sediaan lain yang berkaitan mengikut arahan kerja yang ditetapkan.

DEFINISI

GCMS - Gas Chromatography Mass Spectrometry

GC - Gas Chromatography

MS - Mass Spectrometry

TIC - Total Ion Chromatogram

SIM - Selected Ion Monitoring

PROSEDUR

6.1 Tatacara Penggunaan

Hidupkan GC, MS, komputer dan mesin pencetak.

Masukkan password dan klik [OK] di skrin komputer.

Klik 2x ikon [GCMS Real Time Analysis] dan klik [OK].

Pilih Method yang ingin digunakan

Klik [Data Acquisition] di [Real Time] assistant bar.

Untuk menggunakan method yang sedia ada:

Pilih [Open Method File] di menu [File] dan klik [Download].

Untuk menghasilkan method yang baru:

Pilih [New Method File] di menu [File]. Tentukan semua parameter di tab [Sampler], [GC] dan [MS].

Tentukan parameter instrumen di tab [Sampler], [GC] dan [MS]

Di bawah tab [MS], tentukan mod analisis berdasarkan objektif pengujian seperti yang ditetapkan di dalam SOP analisis spesifik:

Bagi Analisis Kuantitatif (Assay), pastikan parameter tambahan (seperti target ion dan quantitation table) diisi mengikut kaedah analisis spesifik yang dijalankan.

Untuk mengubah method yang sedia ada:

Pilih [Open Method File] di menu [File]. Ubahkan parameter di tab [Sampler], [GC] dan [MS]. Seterusnya pilih [Save Method File As] di menu [File] dan masukkan nama method yang baru dan klik [Save].

Untuk jalankan sampel:

Pastikan tuning dilakukan setiap hari sebelum sampel pertama hendak dijalankan pada hari tersebut dan pastikan laporan adalah lulus.

Klik [Data Acquisition] di [Real Time] assistant bar.

Pilih [Open Method File] di menu [File] dan pilih method yang ingin digunakan.

Pilih [Download Initial Parameters] di menu [Acquisition].

Klik ikon [Tuning] di [Real Time] assistant bar.

Klik ikon [Peak Monitor View] di [Tuning] assistant bar.

Klik ikon [Start Auto Tuning] di [Tuning] assistant bar.

Setelah autotuning selesai, pilih [Save Tuning File As] di menu [File] dan masukkan nama tuning file yang baru dan klik [Save].

Pastikan sampel telah dilarutkan dengan pelarut yang sesuai dan telah ditapis menggunakan penapis 0.45µm kedalam vial.

Letak vial di tempatnya, pastikan nombor kedudukan vial di mana ia diletakkan.

Kemudian klik ikon [Sample Login] di [Acquisition] assistant bar. Masukkan butiran sampel seperti Vial#, Sample Name, Sample ID, Method File, Data File dan maklumat lain. Klik [OK] untuk memulakan injeksi sampel.

Jika sampel yang ingin dijalankan banyak, sampel tersebut boleh dijalankan secara batch. Untuk jalankan sampel-sampel tersebut secara batch adalah seperti berikut:

Klik ikon [Batch Processing] di [Real Time] assistant bar.

Masukkan butiran sampel seperti Vial#, Sample Name, Sample ID, Method File, Data File dan maklumat lain ke dalam Batch Table.

Pilih [Save Batch File As] di menu [File] dan masukkan nama batch file yang baru dan klik [Save].

Klik ikon [Start] di [Batch] assistant bar. Klik [OK] untuk mesej “Do you want to go into the ecology mode after batch processing ends?”.

Analisis Kualitatif (Penyaringan dan Identifikasi)

Setelah sampel selesai analisis, kromatogram yang diperolehi perlu dianalisis untuk mendapatkan maklumat tertentu terutamanya mass spectrum dan identiti sampel tersebut. Data Analisis perlu dijalankan seperti di bawah :

Klik 2x ikon [GCMS Real Time Analysis].

Klik [Qualitative] di [Postrun] assistant bar.

Klik 2x pada Data File yang diingini.

Klik [Peak Integration for All TICs] di [Qualitative] assistant bar. Tentukan parameter untuk integration dan klik [OK].

Klik [Qualitative Table] di [Qualitative] assistant bar. Highlight semua baris di tab [TIC], pilih [Register to Spectrum Process Table] di menu [Edit].

Klik tab [Spectrum Process], pilih [Search All Table] di menu [Similarity Search].

Klik 2x [Done] pada baris pertama di Spectrum Process Table.

Periksa Similarity Search Results untuk setiap baris.

Untuk menyimpan Data Files, klik ikon [Save Data File] menu [File].

Analisis Kuantitatif (Penentuan Kandungan / Assay)

Gunakan prosedur ini untuk pengujian kuantitatif yang memerlukan pengiraan kepekatan.

Klik [Quantitative] di [Postrun] assistant bar.

Klik 2x pada Data File (Standard atau Sampel) yang ingin diproses.

Pastikan Method File yang digunakan mengandungi Quantitation Table yang lengkap (termasuk Target Ion, Reference Ion, dan kepekatan standard).

Klik ikon [Peak Integration]. Semak integrasi puncak bagi setiap analit sasaran mengikut (retention time) yang ditetapkan dalam SOP analisis spesifik.

Bagi penghasilan (Calibration Curve):

Masukkan kepekatan standard ke dalam jadual kuantitasi.

Semak nilai kelinearan (R2). Kriteria penerimaan umum adalah R2 ±0.995 atau mengikut SOP analisis spesifik.

Perisian akan mengira kepekatan sampel secara automatik berdasarkan luas puncak (peak area) atau nisbah luas (area ratio).

Semak Ion Ratio (perbandingan antara Target Ion dan Reference Ion) untuk mengesahkan ketulenan puncak kuantitatif.

Klik ikon [Save Data File] untuk menyimpan keputusan analisis.
