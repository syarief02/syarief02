PROSEDUR

6.1 Tatacara Penggunaan

Buka PC

Masukkan password dan klik OK.

Klik 2X ikon Instrument #1 dan ikon Instrument #1 Data Analysis.

Pilih Method yang ingin digunakan – Pilih window Instrument #1, klik Method dan kemudian pilih Load Method. Untuk menghasilkan method yang baru ikut langkah-langkah berikut:

Pada window Instrument #1, pilih Method dan pilih Load. Kemudian pilih method yang ingin diubah (cth: default.m). Seterusnya pilih Method dan klik Save dan masukkan nama method yang baru dan fail method yang baru akan disimpan.

Klik Method dan pilih Edit Entire Method.

Pilih bahagian mana ingin diubah (method information, instrument/acquisition atau data analysis).

Pilih Method dan klik Save. Method baru akan disimpan dengan parameter-parameter baru.

Untuk jalankan sampel:

Pastikan tuning dilakukan setiap hari sebelum sampel pertama hendak dijalankan pada hari tersebut dan pastikan laopran adalah lulus.

Klik Instrument

Pilih Perform MS Autotune

Pilih Standard Spectra Tune (s.tune) atau Autotune (a.tune). Tunggu seketika sehingga laporan dicetak.

Kemudian pilih Qualify

Pilih Tune Evaluation. Tunggu seketika sehingga lapotan dicetak.

Pastian data s.tune atau a.tune yang terbaru telah disimpan. Pilih view dan Tune and Vacuum Control. Kemudian pilih File dan Save Tune File.

Pastikan sampel telah dilarutkan dengan pelarut yang sesuai dan telah ditapis menggunakan penapis 0.45µm kedalam vial.

Letak vial di tempatnya, pastikan nombor kedudukan vial di mana ia diletakkan.

Kemudian pilih Method dan klik Run (window Instrument #1), masukkan data-data yang diperlukan iaitu Operator name, sample name, vial no., Data File Name. Semak semula data yang dimasukkan dan kemudian klik Run Method untuk mula jalankan sampel.

Atau klik ikon (window Instrument #1)

Kemudian masukkan data-data yang diperlukan (Operator name, sample name, vial no., Data File Name). Setelah selesai klik Run Method untuk mula jalankan injeksi sampel.

Jika sampel yang ingin dijalankan banyak, sampel tersebut boleh dijalankan secara sequence. Untuk jalankan sampel-sampel tersebut secara sequence adalah seperti berikut:

Pilih Sequence dan klik Edit Sample Log Table.

Klik barisan kosong pada jadual dan kemudian klik anak panah di dalam kotak berlabel Type dan pilih jenis sampel yang ingin dijalankan.

Pilih kotak Vial dan masukkan nombor vial.

Pilih Method, masukkan nama method yang ingin digunakan.

Kemudian masukkan Data File Name dan Sample Name.

Pilih Sequence dan klik Load and Run Sequence untuk jalankan sampel.

Setelah sampel selesai analisis, kromatogram yang diperolehi perlu dianalisis untuk mendapatkan maklumat tertentu terutamanya mass spectrum dan identiti sampel tersebut. Data Analisis perlu dijalankan seperti di bawah:

Pilih window Enhanced Data Analysis.

Pilih File, klik Load Data File (pilih path: C:\MSD Chem\\\DATA\testing – Data File disimpan)

Kemudian pilih Data File yang diingini. Klik OK.

Pilih peak yang ingin dianalisis (window TIC). Tukar skala jika ingin besar/kecilkan peak:

Pilih Chromatogran, klik chromatogram scaling.

Pilih Total Ion Current dan klik OK.

Kemudian pilih Enter Absolute Y-axis value, klik OK.

Masukkan nilai paksi-Y yang diingini dan klik OK. (Semakin besar nilai, peak menjadi kecil dan sebaliknya)

Untuk zoom in, klik kiri (tanpa lepas) dan buatkan kotak pada peak yang diingini. Untuk kembali bentuk asal (zoom out), 2X klik kiri pada mana-mana window.

Untuk mendapatkan mass spectrum peak tersebut:

Buatkan kotak dalam peak tersebut dengan klik kanan (tanpa lepas). Kemudian buat kotak pada baseline kromatogram.

Pilih Spectrum dan klik substract.

Kemudian 2X klik kanan pada window spectrum untuk dapatkan mass spectrum bagi peak tersebut yang sepadan dengan mass spectrum library.

Cetak laporan yang diingini.
